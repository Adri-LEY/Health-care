# Health-care

Projet de gestion médicale (React / Node / PostgreSQL).

## 🚀 Comment lancer le projet localement

Pour lancer l'application complète (Base de données, Backend et Frontend) en une seule commande, assurez-vous que **Docker** est démarré sur votre machine, puis exécutez :

```bash
docker-compose up --build
````
